# 🚔 Crime Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **Crime Analysis Dashboard** developed for a City Police Department to analyze crime incidents and support data-driven decision-making.

The dashboard transforms raw crime incident data into meaningful insights about **crime frequency, location, severity, property loss, case resolution, and police resource requirements**.

## 🎯 Objective

The main objective of this project is to help police management:

- Identify the most frequently occurring crime types
- Determine which districts have the highest crime rates
- Identify peak periods of criminal activity
- Analyze crime-related property losses
- Identify areas with high crime severity
- Monitor case resolution rates
- Identify areas requiring greater police attention

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Interactive Dashboard

## 🧹 Data Preparation

The raw crime incident data was cleaned and prepared for analysis.

Major data-cleaning activities included:

- Removing unnecessary spaces
- Cleaning inconsistent text values
- Standardizing crime severity
- Cleaning case status
- Handling blank and missing values
- Standardizing location/address information
- Creating calculated/cleaned fields for analysis

## 📈 Dashboard Features

The interactive dashboard provides insights into:

### 1. Crime Frequency
Identifies the crime types occurring most frequently.

### 2. District-wise Crime Analysis
Shows the distribution of crimes across different police districts.

### 3. Crime Activity Trends
Helps identify periods when crime activity is at its peak.

### 4. Property Loss Analysis
Identifies crime categories associated with the highest property losses.

### 5. Crime Severity
Analyzes areas based on the severity of reported incidents.

### 6. Case Resolution
Shows the proportion of cases that have been resolved compared with unresolved cases.

### 7. Police Resource Allocation
Helps identify areas where additional police attention and resources may be required.

## 🎛️ Interactive Features

The dashboard includes interactive **slicers and filters** that allow users to explore the data based on different categories such as:

- Year
- Crime Type
- District
- Case Status
- Severity

These filters allow management to perform focused analysis and compare different segments of the crime data.

## 💡 Key Business Insights

The analysis helps answer important business questions such as:

- Which crime type occurs most frequently?
- Which district has the highest number of crimes?
- When does crime activity peak?
- Which crime types cause the highest property loss?
- Which areas have the highest crime severity?
- What percentage of cases are resolved?
- Which areas require more police attention?
